# AGENTS.md — if you are an AI agent reading this repo

Welcome. This repo is a complete, researched build kit. Follow these rules and you will
produce work the founder can actually ship.

## Mandatory first reads
1. `00-SHARED-CONTEXT.md` — every fact you need about the APIs, fees, limits, market size, competitors, and brand tokens. Do not invent API behaviour; verify against `docs.polymarket.com` before writing code. CLOB V1 is dead.
2. `AGENTS-safe rules` below.

## Rules
1. **Work in prompt order.** Each prompt in `prompts/` assumes the outputs of the ones before it. If an earlier deliverable is missing, produce it first (they are designed to be generated by you).
2. **Start from the approved brand kit.** `brand/BRAND-KIT.md` is a completed Brand Lock in the shape of the vendored `skills/higgsfield-ai-skills/higgsfield-brandkit` skill. Its `fixed` fields are immutable without explicit human approval. Use `SKILLS.md` for the CLI/built-in-generator substitution.
3. **Never redraw the mark with an image model.** Compose from `brand/svg/mark.svg`.
4. **No copied identity.** We rebuild gmgn's information architecture and borrow Polymarket's *palette register* only. Never reproduce either product's logo, icons, copy, or assets.
5. **Fail closed.** Stale or missing price ⇒ show it and disable trading. No money moves without the risk gate. No secrets in code, logs, errors, or telemetry.
6. **No floats in the money path.** No raw number rendering in the UI. Every price surface carries a freshness indicator.
7. **Tests are the definition of done.** The money-path matrix in `prompts/P13` must run in CI before any real funds.
8. **Surface unknowns.** If you cannot verify something, mark it `[UNVERIFIED]` instead of guessing.
9. **Budget awareness.** The founder's envelope is <$10k. Every infrastructure or vendor recommendation must carry a monthly cost.
10. **Honest revenue arithmetic.** Builder fees cap at 100 bps taker. $1M ARR ≈ $8.3M/month routed ≈ top-3 builder. Year-one realistic is $80k–$400k. Never write projections that ignore this.
